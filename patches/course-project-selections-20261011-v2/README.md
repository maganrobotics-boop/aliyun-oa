# Semester course projects and industrial laboratory applications

Apply only after the project-applications-20261011-v1 overlay. This overlay verifies each existing file against its deployed baseline SHA-256 and copies the shared catalogue and selection module.

Each authenticated student may choose one main course project per Beijing-time semester (fall September–January, spring February–August). Selection opens the chapter immediately and reserves a SQLite quota before asynchronous OA delivery. A durable outbox retries interrupted delivery. Supporting exercises belong to their main project; earlier semester selections remain accessible.

Laboratory applications show the three official industrial products, require a real recorded Newbie Village final pass, and retain the existing evidence, attachment and designated-reviewer flow. OA receives native approvals with immutable revision evidence for both types. OA independently checks the student/semester quota. Teacher replies use the existing signed, durable permission channel.
