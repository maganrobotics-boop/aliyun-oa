# 企业微信应用内免登录

已绑定企微身份的成员，从企微工作台中的 OA 自建应用打开 `https://oa.omindos.cn/` 时，登录页自动发起 `snsapi_base` 网页授权。服务端以企业 ID 和企微 UserID 查找已绑定且激活的原 OA 成员，签发七天 OA 会话，并返回原审批链接或工作台。

- 自建应用首页保持 OA 正式首页。应用仍需配置当前可信域名、可信 API IP 和成员可见范围。
- 新入口为 `/api/auth/wecom/start`，固定回调为 `/api/auth/wecom/callback`。沿用当前自建应用配置，Secret 仅在服务器读取。
- 企微浏览器标识仅决定显示和跳转方式。实际身份由企微接口验证，包括同一应用的成员可见范围与激活状态。
- 首次未绑定者需要先通过原登录方式进入 OA，在设置中绑定本人企微账号。静默登录不会新建成员、按姓名匹配、合并账号或放宽 OA 权限与 NDA 准入。
- OAuth state 与当前浏览器 HttpOnly 随机 Cookie 绑定，五分钟有效且只能消费一次。现有数据库表可直接使用，无需数据库迁移。
- 明确退出后停在退出提示页；失败后停在重试页，避免反复自动跳转。普通浏览器、飞书和企微扫码绑定流程保持原行为。
- 登录仅为当前浏览器新建会话，不撤销其他浏览器的有效会话。

## 发布与验收

候选必须从当前生产源码复制，只覆盖本改动涉及的文件，保留已上线诊断及业务补丁。Nginx 的新回调必须关闭 access log，沿用现有身份头清理和可信反向代理设置。构建前后对照当前生产目录，避免覆盖并行发布。

自动验证：类型检查、统一扫码/企微 OAuth/退出登录专项测试、阿里云构建、普通浏览器与企微浏览器入口、错误及未绑定提示。真实企微身份的静默授权最终仍需在已绑定成员的企微客户端打开应用验收，不能用模拟响应代替。

回退只切回前一代码目录及对应 Nginx 配置，不恢复旧业务数据库。
